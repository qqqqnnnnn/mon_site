Effet Fondu Bas

Cette carte apparaît progressivement en remontant légèrement grâce à la classe CSS reveal et à JavaScript.

Détection Automatique

Le script calcule la position de l'élément dans la page. Dès qu'il entre dans l'écran, l'animation se déclenche.

Effet Latéral Gauche

On peut facilement personnaliser l'effet. Cette carte arrive depuis la gauche de l'écran (reveal-left).

Fluidité

Les transitions CSS garantissent une animation fluide à 60 images par seconde sur ordinateur comme sur mobile.

Fin de la page

Vous pouvez ajouter autant d'éléments animés que vous le souhaitez en leur appliquant simplement la classe requise.
